# 睡眠 App 原型（收入最大化优化版）

## 1. 产品定位（从“可用”到“高收入”）
- **产品名（暂定）**：DreamPulse
- **一句话定位**：用 App 快速筛出“高付费意愿 + 高睡眠困扰”人群，再通过会员分层与智能硬件组合，放大 ARPU 与 LTV。
- **核心策略**：
  1. App 先验证效果（低门槛进入）
  2. 订阅承接日常价值（稳定现金流）
  3. 硬件放大体验与客单（一次性高收入）
  4. 配件/增值服务做复购（持续收入）

## 2. 用户分层与收入分层
### 2.1 用户价值分层（RFM 思路）
1. **A层（高价值）**：连续使用 >14 天、愿意记录睡眠、主观改善明显。
2. **B层（中价值）**：每周使用 2-4 次，效果感知一般。
3. **C层（低价值）**：首周流失风险高、价格敏感。

### 2.2 分层变现路径
- **A层**：重点推「年费会员 + 硬件组合包 + 延保」
- **B层**：重点推「月费会员 + 限时硬件券」
- **C层**：重点推「7天体验包 + 单次付费程序」

## 3. 收入模型设计（最大化）
### 3.1 软件收入：订阅 + 单次付费并行
- **免费层**：每日 1 个基础程序 + 基础日志。
- **会员层（Pro）**：
  - 月付：¥48
  - 季付：¥128（比月付省 11%）
  - 年付：¥398（重点主推）
- **单次付费（IAP）**：
  - 7天急救包（焦虑夜、夜醒包）¥18-¥30
  - 进阶主题包（深睡、冥想、差旅时差）¥30-¥68

### 3.2 硬件收入：高毛利组合优先
- **智能眼罩标准版**：¥399
- **智能眼罩Pro（更舒适材质 + 更稳光路）**：¥599
- **组合包（主推）**：
  - 标准版 + 年费会员：¥699（锚定优惠）
  - Pro版 + 年费会员 + 1年延保：¥999（利润优先）

### 3.3 后续复购收入
- 替换眼罩套：¥59/套
- 清洁护理包：¥39
- 延保服务：¥99/年
- 睡眠顾问轻咨询（可选）：¥199/次

## 4. 关键漏斗（以营收为北极星）
1. **激活**：首次 24 小时内完成 1 次训练
2. **价值感知**：3 日内完成 3 次训练并提交困意评分
3. **首次付费**：第 4-7 天触发首购（会员/小额IAP）
4. **高客单转化**：第 7-14 天推硬件组合包
5. **留存复购**：30 天内配件/续费二次变现

## 5. 信息架构（Revenue-first）
底部导航 5 Tab：
1. **首页**：今晚推荐 + 会员权益入口 + 限时活动
2. **程序**：免费/会员/单次包清晰分层
3. **设备**：连接、校准、商城、延保
4. **报告**：效果证明 + 升级建议
5. **我的**：订阅、订单、优惠券、邀请返利

## 6. 核心页面原型（强调转化）
### 6.1 首页（Tonight）
- 顶部：昨日睡眠评分与“改善趋势”。
- 中部 CTA：`开始今晚助眠`。
- 收入模块：
  - 会员权益横幅（A/B 测试文案）
  - 限时组合包卡片（倒计时 + 社会证明）

### 6.2 训练完成页（最关键变现节点）
- 展示本次收益：放松度、预计入睡缩短时间。
- 弹层策略：
  - 第1次完成：引导 3 天挑战（不强卖）
  - 第3次完成：首购优惠（会员 7 折）
  - 第5次完成：硬件升级弹层（解决手持痛点）

### 6.3 设备商城页（高客单）
- 商品卡：标准版 / Pro版 / 组合包（默认高亮组合包）。
- 信任增强：真实评价、30天无忧退、睡眠改善案例。
- 下单机制：分期支付、券后价、加价购配件。

### 6.4 报告页（用效果驱动付费）
- 指标：入睡时长下降、夜醒减少、连续达标天数。
- 推荐引擎：
  - 轻改善：推荐会员
  - 中高改善：推荐硬件组合包
  - 复购窗口：推荐配件与延保

## 7. 动态定价与促销机制
- **首购窗口**：第3-7天给一次“限时低价”。
- **防流失折扣**：连续3天未打开，发回流券。
- **分层券策略**：
  - A层：少打折，多给增值（延保/专属程序）
  - B层：中等折扣促转化
  - C层：低价体验包拉回
- **节日大促**：世界睡眠日、618、双11 做硬件主场。

## 8. 增长与分销（拉新即营收）
- 邀请机制：邀请好友完成3次训练，双方得会员天数。
- KOL合作：睡眠博主 + 职场效率博主双渠道投放。
- 企业团购：B端员工睡眠福利包（SaaS化后台可后置）。

## 9. 关键指标（以收入最大化为目标）
- **收入指标**：
  - MRR / ARR
  - ARPPU
  - 30日 LTV
  - 硬件客单价与毛利率
- **漏斗指标**：
  - 3日训练完成率
  - 首购转化率（D7）
  - 组合包转化率（D14）
  - 90日复购率（配件/续费）
- **效率指标**：
  - CAC 回收周期
  - ROAS（分渠道）

## 10. 版本规划（增长与收入并行）
### MVP（1-2个月）
- 核心训练流程 + 基础报告
- 会员体系（月/年）
- 首购优惠与基础支付链路
- 设备连接与基础商城

### V2（3-4个月）
- 用户分层定价引擎
- 组合包智能推荐
- 配件与延保二次销售
- 邀请裂变与渠道归因

## 11. 可执行的 30 天收入冲刺计划
1. 上线 3 档价格与 2 套组合包。
2. 在“训练完成页”上线首购弹层 A/B 测试。
3. 在“报告页”上线硬件推荐卡（基于改善趋势触发）。
4. 对未付费用户做 3 次分层触达（站内 + Push）。
5. 每周复盘：转化、客单、退款率，滚动调价。

> 目标：在不显著牺牲留存的前提下，优先提升 D14 收入与 30 日 LTV。

## 12. 下一步落地（继续下一步）
### 12.1 两周执行排期（Sprint）
- **Week 1（搭好变现骨架）**
  1. 完成会员页（价格梯度、权益对比、支付入口）
  2. 完成训练完成页弹层策略（第1/3/5次）
  3. 完成设备商城页（标准版/Pro/组合包）
  4. 埋点上线（曝光、点击、支付、退款）
- **Week 2（开始提收入）**
  1. 上线 A/B Test：会员文案、首购折扣力度
  2. 上线分层触达：A/B/C 用户 push 文案差异化
  3. 上线“未支付挽回”流程（离开支付页 30 分钟提醒）
  4. 复盘并调价：按转化率和退款率调首购策略

### 12.3 A/B 实验矩阵（先做 3 个）
1. **Paywall 主标题**：
   - A：强调效果（“7天缩短入睡时长”）
   - B：强调成本（“每天不到¥1.1”）
2. **首购优惠形式**：
   - A：直接打折
   - B：送延保/程序包
3. **组合包展示顺序**：
   - A：先展示标准版
   - B：先展示 Pro 组合包（锚定高价）

### 12.4 交付清单（给设计/研发）

### 12.5 本阶段验收标准（Definition of Done）
- D7 首购转化率较基线提升 **≥15%**
- 组合包占硬件订单比例 **≥35%**
- 退款率控制在 **<8%**
- 不降低次周留存（波动不超过 2 个百分点）
